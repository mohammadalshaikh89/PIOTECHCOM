2 · Run the extract query on the bank's database

One read-only query returns the codes and English / Arabic names of every ticked list parameter for this bank.

  1. Run it in SQL Developer as the BI_DWH user.
  2. Right-click the result grid → Export → format excel 2003+ (xlsx) → save.
  3. If one table raises an error, untick that parameter above and copy the query again.

    


    

      
3 · Upload the query result
The exported .xlsx (or .csv). The value counts appear in the table in step 1.

      
      

      

    


    

      
4 · Generate the bank's form
A protected .xlsx: codes and names are locked, the bank only picks a score (0–5) from a list, with instructions in Arabic and English. Send it to the bank, then load the returned file in “Load the returned form”.
